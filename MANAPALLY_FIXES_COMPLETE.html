🎯 Issue #1: Game Stuck on "Awaiting Arjun"

Problem: After clicking "Start Game", the interface showed "Awaiting Arjun" but the game never started. The "Roll the dice" button appeared but was unclickable.

Root Causes:

  • Button disabled condition checked activePlayer.id !== 'host' instead of 'p1'
  • Button text display checked activePlayer.id === 'host' instead of 'p1'
  • Roll dice handler guard checked activePlayer.id !== 'host' instead of 'p1'
  • No automatic trigger for AI turns when game initializes

Solution:

  • ✅ Fixed button disabled condition: activePlayer.id !== 'p1'
  • ✅ Fixed button text: activePlayer.id === 'p1' ? 'Roll the dice' : `Awaiting ${activePlayer.name}`
  • ✅ Fixed roll handler guard: activePlayer.id !== 'p1'
  • ✅ Added useEffect to auto-trigger AI turns after 850ms
  • ✅ Refactored completeAITurn to use dynamic activePlayer.id and activePlayer.name

🏢 Issue #2: Purchase Logic Not Working

Problem: Landing on unowned properties (Kaveri Power Company, Golconda Fort Avenue) didn't trigger purchase offers. No way to buy or sell properties.

Root Cause: Economy helper functions existed but weren't integrated into turn execution flow.

Solution: Added property economics to both human and AI turn execution:

// Check property ownership after landing
if (deed && deed.owner !== playerId && !deed.mortgaged) {
  // Pay rent or handle insolvency
  const rent = Estate.rentFor(deeds, landedSpace.id, total, spaces);
  if (rent > 0) {
    if (balances[playerId] < rent) {
      await handleInsolvency(playerId, rent, deed.owner);
    } else {
      transferCash(playerId, deed.owner, rent);
    }
  }
} else if (!deed && landedSpace.price) {
  // Offer purchase
  if (playerId === 'p1') {
    await offerPurchase(playerId, landedSpace.id);
  } else {
    aiDecidePurchase(playerId, landedSpace);
  }
}

🔄 Issue #3: Turn Not Advancing After AI Move

Problem: After AI player (Arjun) took their turn, control didn't return to human player. Game stuck showing "Awaiting Player 2".

Root Cause: Missing automatic trigger for next turn when active player changes.

Solution: Added useEffect that watches activePlayer.id:

useEffect(() => {
  if (gameOver || movementInProgressRef.current ||
      isMoving || isRolling || activePlayer.id === 'p1') {
    return;
  }
  const timer = setTimeout(() => {
    movementInProgressRef.current = true;
    completeAITurn();
  }, 850);
  return () => clearTimeout(timer);
}, [activePlayer.id, gameOver, isMoving, isRolling, completeAITurn]);
