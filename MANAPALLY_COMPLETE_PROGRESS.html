💡 Technical Achievements

Separation of Concerns

Pure economy logic in estate.js with zero React dependencies enables testing without mounting components. All functions accept spaces parameter for maximum testability.

Dynamic Player System

Refactored from hardcoded 2-player (host/rival) to dynamic p1...p4 with activeSeatForTurn() deriving active player from turn count.

SVG Component Architecture

PieceMark and PropertyTally use currentColor inheritance for dynamic color tinting via CSS seat classes.

Promise-Based Modal Pattern

Purchase and insolvency modals return Promises that resolve when user makes decision, enabling clean async turn flow.

Computed State

activePlayerIndex derived from turnCount via useMemo eliminates manual turn switching and state inconsistencies.

Ref Mirroring

positionsRef tracks positions across async boundaries so card-driven moves read current position, not stale closure value.

🎯 Design Patterns

  • Pure Functions: All estate.js functions are pure with explicit spaces parameter
  • Optimistic Updates: UI updates immediately with automatic rollback on error
  • Computed State: Active player derived from turn count, never stored
  • Ref Mirroring: Position ref tracks state across async card execution
  • Async Modals: Promise-based handlers enable sequential turn execution
  • CSS Custom Properties: Seat colors as classes, inherited via currentColor
  • Component Composition: Reusable PieceMark with variants (token, stamp, chip)
